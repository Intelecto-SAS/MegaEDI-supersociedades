# Identidad visual en la demo

La interfaz de EDI 360 sigue el *Manual de Identidad Visual* de la Superintendencia de Sociedades (2024), con estas piezas:

| Elemento | Aplicación en la demo |
|---|---|
| Color institucional | `#962D46` (R150 G45 B70) |
| Tipografía principal | Nunito Sans (Verdana queda para plantillas Office, no para esta interfaz) |
| Escudo y nombre | Versión a color sobre fondo blanco, sin rotar ni recolorear |
| Bandera | Franja 50 % amarillo `#FFC800`, 25 % azul `#003189`, 25 % rojo `#D80025` |
| Pie de piezas | Línea en color institucional |

La demo no sustituye la aprobación del Grupo de Comunicaciones para piezas oficiales. El logo no se usa para acreditar productos ajenos a la Entidad.
