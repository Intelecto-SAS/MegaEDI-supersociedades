# Conexiones simuladas

Las 23 filas del informe (sanciones de contadores, RUES, identidad, NIT, antecedentes, DIVIPOLA, CIIU, festivos, UVT, juzgados, firma, catastro, nómina, socios, beneficiario final, pólizas, títulos, tarjetas y SECOP II) existen como catálogo.

Cada una puede responder bien, con discrepancia, tarde, con error o caerse. El centro de demostración fuerza una falla y la restablece. Se guarda la fecha del último intento. Nada de esto consulta entidades reales.
