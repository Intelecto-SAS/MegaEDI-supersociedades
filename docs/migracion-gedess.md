# Modernización GeDeSS (simulación)

Dos repositorios:

- **Heredado:** radicados históricos ficticios, estados inconsistentes, duplicados, sin expediente o sin responsable.
- **EDI Documental:** modelo normalizado, un responsable, documentos versionados, auditoría.

Estados de una capacidad: no iniciado, inventariado, preparado, migración en prueba, pendiente de conciliación, conciliado, paralelo controlado, traslado autorizado, consulta histórica, cerrado para nuevas operaciones.

El traslado impide escribir lo nuevo en los dos lados. La reversión se bloquea si ya hay actuaciones nuevas incompatibles. El histórico no se elimina. En pantalla se advierte que es una simulación local.
