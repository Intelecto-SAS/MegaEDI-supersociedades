# Roles y permisos

Dos capas:

- Por rol: qué puede hacer (radicar, repartir, aprobar, consultar).
- Por ámbito: de quién son los casos (propios, del equipo, de la dependencia, de la región, institucionales o de un caso puntual).

Un cargo directivo no abre por sí solo expedientes disciplinarios reservados. Un intendente no ve otra región. Dirección TIC no hereda reserva. Control Interno consulta y no altera el registro original.

El menú, las búsquedas y la API usan la misma matriz. El administrador de demostración es el único que cambia de funcionario y restablece el entorno.
